# GeoChaos v0.1.1

IP2Location-powered dependency failure testing for web applications.

Observe passing browser journeys, group external origins by reported country or
ASN, inject controlled failures, and inspect functional outcomes in self-contained
HTML/JSON reports. The bundled demo contrasts a fragile checkout with a resilient fix.

This release adds a public demo-site builder, opt-in GitHub Pages deployment,
repository personalization, lockfile setup/repair, release checks, publishing and
contest instructions, and visible development attribution.

**Vibe coded with ChatGPT Pro 6.** See CREDITS.md for the AI-development disclosure
and maintainer responsibilities. The source is MIT-licensed; provider data has
separate terms. IP Geolocation by IP2Location.io.

Start with README.md. Use PUBLISHING.md to reproduce the release and submit the
repository. The historical samples have synthetic labels and were captured in
inline mode; they do not represent live API results or ordinary navigation.
See docs/VERIFICATION.md and the repository's actual CI runs for evidence and
limits. This release does not claim a security audit, total resilience, geographic
outage simulation, or approval by the contest organizer.
